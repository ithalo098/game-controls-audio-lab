# Game Controls & Audio Lab

Laboratório de interface com controles de movimento, prévia interativa e ajustes de áudio.

## Estrutura

- [`src/`](./src/)
- [`public/`](./public/)
- [`package.json`](./package.json)

## Visão geral

O código e os materiais deste repositório estão organizados para consulta e evolução do projeto. As funcionalidades descritas refletem os arquivos presentes, sem pressupor uma publicação em produção.

## Tecnologias

- react
- tailwindcss
- typescript
- vite

## Executar localmente

```sh
git clone https://github.com/ithalo098/game-controls-audio-lab.git
cd game-controls-audio-lab
npm install
npm run dev
```

Para gerar a versão de distribuição: `npm run build`.
